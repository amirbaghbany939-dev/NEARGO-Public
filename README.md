# NEARGO

**Closer to Your Goal.**

سامانه برنامه‌ریزی تحصیلی ویژه دانش‌آموزان پایه دوازدهم در دو مسیر ریاضی‌فیزیک و علوم تجربی.

## امکانات
- داشبورد شخصی با تاریخ شمسی، آب‌وهوا و نمای متناسب با رشته
- حساب کاربری جداگانه برای هر دانش‌آموز و همگام‌سازی آنلاین
- برنامه‌ریز دستی و ساخت برنامه پیشنهادی هفت‌روزه با توجه به نقاط ضعف، ساعت خواب و برنامه ثابت
- ثبت مدرسه و کلاس‌های هفتگی
- ثبت مباحث و سطح تسلط
- زمان‌سنج مطالعه و ثبت خودکار گزارش
- ثبت آزمون، نتیجه درس‌ها و تحلیل درصد
- فهرست منابع و راهنمای قاعده‌محور تحصیلی

## انتشار
این پروژه به‌صورت یک وب‌سایت استاتیک روی GitHub Pages منتشر می‌شود. در مخزن، از مسیر **Settings → Pages**، منبع انتشار را روی **GitHub Actions** قرار دهید. پس از آن هر push به شاخه `main` به‌صورت خودکار منتشر می‌شود.

## پایگاه داده
رابط کاربری از Supabase Auth و جداول دارای Row Level Security استفاده می‌کند. کلید داخل مرورگر از نوع publishable است؛ کلیدهای service-role یا secret نباید در کد سمت کاربر قرار بگیرند.

## محدودیت نسخه فعلی
راهنمای تحصیلی فعلی تحلیل‌گر قاعده‌محور است و گفت‌وگوی هوش مصنوعی زنده ادعا نمی‌کند. برنامه پیشنهادی، پیش‌نویس قابل ویرایش است و برای دقت بیشتر باید برنامه مدرسه و کلاس‌ها کامل ثبت شوند.
